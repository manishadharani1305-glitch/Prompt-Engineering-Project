# 🤖 Prompt Engineering App

An interactive Streamlit application that demonstrates different Prompt Engineering techniques using a local Hugging Face Large Language Model (LLM).

---

## 🚀 Project Overview

The **Prompt Engineering App** is an interactive AI application developed to understand how different prompting techniques influence the responses generated by a Large Language Model.

The application allows users to enter a task, select a prompting technique, adjust LLM settings, and generate an AI response.

The project implements six important Prompt Engineering techniques:

- Zero-shot Prompting
- One-shot Prompting
- Few-shot Prompting
- Chain-of-Thought (CoT)
- Manual Chain-of-Thought
- Tree-of-Thought (ToT)

The application uses **Streamlit** for the user interface and a local **Hugging Face SmolLM2** model for response generation.

## 🎯 Objectives

The main objectives of this project are:

1. To understand the concept of Prompt Engineering.
2. To implement different prompting techniques.
3. To understand how prompt structure affects LLM responses.
4. To build an interactive AI application using Streamlit.
5. To experiment with Temperature and Maximum Tokens.
6. To use a Hugging Face language model locally.
7. To understand how different prompting strategies guide an LLM.
8. To provide a simple interface for experimenting with prompts.
